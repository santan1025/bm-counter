How to set this up (once)

      

        1. Create a free project at supabase.com.

        2. Open SQL Editor, paste the code below, press Run.

        3. Open Project Settings → API. Copy the Project URL and the anon public key into the boxes above.

        4. Pick a Shop Code and use the same one on every phone in the shop.

        5. Press Sync Now on each device.
      

      
create table if not exists cm_records (
  shop text not null,
  kind text not null,
  rec_id text not null,
  data jsonb,
  deleted boolean default false,
  updated_at timestamptz default now(),
  primary key (shop, kind, rec_id)
);
create index if not exists cm_sync_idx on cm_records (shop, updated_at);
alter table cm_records enable row level security;
create policy "shop access" on cm_records
  for all to anon using (true) with check (true);

      
      
Your key is stored only on this device — it is never written into the app file, so publishing the app link does not expose it. Treat the key like a shop password.
